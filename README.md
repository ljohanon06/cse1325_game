# Enter the Dungeon
Enter the Dungeon is a dungeon-crawler game focusing on improving typing speed in a fun way. The player explores through the dungeon, meeting and talking to NPCs, and if that meeting results in a fight, they must type as fast as possible in order to win.

To play, download everything, navigate to directory, and run the following commands

javac -d bin *.java

java Main.java

If you click off of the terminal you must click back onto the popup at the bottom of the screen to reconnect.
